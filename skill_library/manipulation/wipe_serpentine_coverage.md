# wipe_serpentine_coverage

> **Purpose:** 平面覆盖类任务（擦拭/扫掠）的路径生成与接触控制
> **Ownership:** Coordinator adds generalizable patterns. Actors do not edit this file.

## Problem

擦拭任务的失败模式与抓取完全不同：目标不是"到达一点"而是"覆盖一片"。
单程蛇形会在污渍边缘留死角；垂直下压姿态（[0,0,1,0]）在贴桌高度触发
Piper 腕限位死区；全速接触会把擦板弹离液面或撞飞目标，coverage 判定
（访问覆盖率 ≥50%）因此失败。

## When to Apply

- 成功判定是面积覆盖（而非物体位姿）的任务：擦拭/扫掠/涂抹
- 工具头需要持续软接触桌面的任务

## Strategy

1. **双程蛇形**：SAM3 掩码 → 世界点云 bbox（内缩 5mm margin）→ 横向
   蛇形（行距 3cm）+ 纵向蛇形（列距 4cm）双程覆盖；
   `interpolate_segment(step=0.02)` 密化。
2. **38° 滚转锁定**：贴桌平板姿态用倾角 38° + `free_approach_roll=False`
   ——全姿态 IK 实测唯一整路径收敛组合（严格顶朝下必死）。
3. **软接触**：接触段裸 move_to_joints + graze 容差
   `tol=0.06, fk_tol=0.05`；入接触前最后 5cm 降速。
4. **区域间转移走 RRT**（rrt_move_discipline 的分层纪律不变）。
5. **擦板几何补偿（必修盲点）**：擦板面心 ≠ grip_site——面心在 site 沿
   逼近轴 **+90mm**（`WIPER_FACE_L = 0.090`）处。倾斜姿态下面心与 site
   水平错开 L·sin(tilt)（38° 时 ~5.5cm），**不做补偿会把擦板拖出污渍**；
   IK 目标点必须用 `pad_to_site()` 逐点换算，严禁把 grip_site 直接打到
   污渍坐标上（实测：不补偿时 7 tilt × 4 z-lift 全网格 IK 零收敛）。

### Code Sketch

```python
def _overhead_quat(tilt_deg=38.0, az_deg=0.0):
    """倾斜姿态构造（共轭翻转不可省）：逼近轴离竖直 tilt°、方位 az°。"""
    t, a = np.deg2rad(tilt_deg), np.deg2rad(az_deg)
    approach = np.array([np.sin(t) * np.cos(a), np.sin(t) * np.sin(a), -np.cos(t)])
    yaxis = np.array([1.0, 0.0, 0.0]) - approach[0] * approach
    yaxis /= np.linalg.norm(yaxis)
    xaxis = np.cross(yaxis, approach)
    R = np.column_stack([xaxis, yaxis, approach]) @ np.diag([-1.0, 1.0, -1.0])
    return rotation_matrix_to_quaternion(R)

WIPER_FACE_L = 0.090   # grip_site→擦板面心 沿逼近轴距离（wiper_gripper.xml 实测）

def pad_to_site(p, press, tilt_deg=38.0, az_deg=0.0):
    """面心接触点 p（污渍平面上）→ grip_site 目标：xy 后撤 L·sin(t)，z = L·cos(t) - press。"""
    t, a = np.deg2rad(tilt_deg), np.deg2rad(az_deg)
    horiz = WIPER_FACE_L * np.sin(t)
    return np.array([p[0] - horiz * np.cos(a),
                     p[1] - horiz * np.sin(a),
                     WIPER_FACE_L * np.cos(t) - press])

def serpentine(x_min, x_max, y_min, y_max, row_step=0.03):
    """横向蛇形面心路径（配合 pad_to_site 逐点换算后执行）。"""
    ny = max(3, min(6, int(np.ceil((y_max - y_min) / row_step)) + 1))
    nx = max(3, min(5, int(np.ceil((x_max - x_min) / 0.04)) + 1))
    xs, ys = np.linspace(x_min, x_max, nx), np.linspace(y_min, y_max, ny)
    waypoints = []
    for i, y in enumerate(ys):
        for x in (xs if i % 2 == 0 else xs[::-1]):
            waypoints.append(np.array([x, y, 0.0]))
    dense = [waypoints[0]]
    for i in range(len(waypoints) - 1):
        seg = interpolate_segment(waypoints[i], waypoints[i + 1], step=0.02)
        dense.extend(seg[1:])
    return dense
```

执行形态（先算后动）：`quat = _overhead_quat(38.0, az)`；对每个面心点 p，
`q = solve_ik(pad_to_site(p, press=0.002, 38.0, az), quat,
free_approach_roll=False)`——路径段必须滚转锁定；转移/撤离段可用
`free_approach_roll=True`；全链预解收敛后接触段 `move_to_joints(q, tol=0.06,
fk_tol=0.05)` 逐点重放。

  调用的完整负样本）——几何补偿是必要条件不是优化项。

## Limitations

- 38° 倾角是擦板工具头（PiperWiperGripper）的特解；换工具须重新扫
  姿态族。
- `WIPER_FACE_L = 0.090` 绑定当前 wiper_gripper.xml 几何（38° 补偿
  安装的 12×5cm 海绵板）；改模型/换垫必须重测该值。
- coverage 判定依赖场景类的访问统计（_get_observations 侧效应）——
  任务代码侧只需保证路径覆盖，判定由引擎自动完成。
