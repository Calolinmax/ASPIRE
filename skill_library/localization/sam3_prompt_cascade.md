# sam3_prompt_cascade

> **Purpose:** 开放词汇物体定位的可靠级联（SAM3 主力 + molmo 兜底 + 面积过滤）
> **Ownership:** Coordinator adds generalizable patterns. Actors do not edit this file.

## Problem

SAM3 文本提示对颜色+类别词敏感：提示词稍有偏差（"red cube" vs 场景实际描述）
就返回空掩码列表；不过滤时机械臂自身常被误检为目标（臂在 robotview 视野内
占比大）。直接把 masks[0] 当目标会静默选错（论文 App A Fig 8 同款失败模式）。

## When to Apply

- segment_sam3_text_prompt 返回 []（zero masks → prompt 不当或遮挡）
- 检出掩码数量/面积异常（>12000px 多半是臂；<50px 是噪声）
- 同名多实例场景需要按方位词消歧（front/back/left/right）

## Strategy

1. **级联兜底**（open_details 三份官方代码同款）：text prompt 空 →
   point_prompt_molmo 打点 → segment_sam3_point_prompt 转掩码 →
   best-score 兜底。
2. **面积过滤**：只保留 50–12000px 的掩码（排机械臂与噪点）。
3. **提示词回落**：主提示失败换近义（"red cube"→"red block"）；
   两词优先于长句。
4. **点云统计**：mask_to_world_points 后取 median center / p95 top_z /
   p5 min_z；有效点 <10 个视为本次定位失败，重新观测。
5. **先让拍再观测**：起手 TUCK 收臂（execute_legs_rrt([TUCK_Q])），
   让开 robotview 走廊再 get_observation——臂挡视野是 zero masks 的
   高频根因。
6. **多实例消歧**：≥2 个同类实例时按任务方位词排序选择（x 轴=前后，
   y 轴=左右，基座系）。

### Code Sketch

```python
def localize(rgb, depth, K, E, prompts, min_px=50, max_px=12000):
    """级联定位：多提示词 × (text→molmo→point) × 面积过滤。返回 (center, top_z, min_z) 或 None。"""
    for prompt in prompts:
        masks = segment_sam3_text_prompt(rgb, prompt)
        if not masks:
            pts = point_prompt_molmo(rgb, prompt)
            p = list(pts.values())[0] if pts else (None, None)
            if p[0] is not None and p[1] is not None:
                masks = segment_sam3_point_prompt(rgb, (int(p[0]), int(p[1])))
        valid = [m for m in (masks or [])
                 if m.get("mask") is not None
                 and min_px <= int(np.sum(m["mask"] > 0)) <= max_px]
        if not valid:
            continue
        best = max(valid, key=lambda m: float(m.get("score", 0.0)))
        pts3 = mask_to_world_points(best["mask"].astype(np.uint8), depth, K, E)
        pts3 = pts3[np.isfinite(pts3).all(axis=1)]
        if pts3.shape[0] < 10:
            continue
        return (np.median(pts3, axis=0),
                float(np.percentile(pts3[:, 2], 95)),
                float(np.percentile(pts3[:, 2], 5)))
    return None
```

- 2026-08-04 Stack PASS：级联兜底在 "red cube" 零检出时经 molmo→point
  路径成功定位（当日 trace 的 sam3/molmo 标注图佐证）。
- 33/33 契约测试 B/E 区：SAM3 text/point 输出契约与面积过滤行为锁定。
- 官方三份任务代码（open_details/）全部使用同一级联——论文兜底链的
  直接证据（point_prompt_molmo 为其 SAM3 级联 shim 等价物）。

## Limitations

- 面积阈值 50–12000px 按 640×640 robotview 标定；换相机分辨率须重标。
- 渲染深度存在已表征偏差（约 2.1cm@59cm，渲染侧冻结区）——z 向精细
  操作以 p5/p95 相对统计为准，勿用绝对深度值硬编码阈值。
