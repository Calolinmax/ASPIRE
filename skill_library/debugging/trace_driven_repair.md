# trace_driven_repair

> **Purpose:** 用执行 trace 做失败归因的标准流程（修第一现场，不修表象）
> **Ownership:** Coordinator adds generalizable patterns. Actors do not edit this file.

## Problem

修复失败的常见错误：只看最终报错就改代码（traceback 指向的往往是受害者
而非肇事者）；在同一策略上反复微调（local repair loop）；凭猜测改感知提示词
而不看标注图。trace.json 每条记录含输入/输出/前后帧/标注图/碰撞事件——
失败证据全在里面，不看就改等于盲修。

## When to Apply

- 任何执行失败（success=false 或 RuntimeError）后的第一轮诊断
- ≥2 个 seed 出现同一症状（一次失败是噪声，重复失败才是模式——论文
  App A Fig 7 的入库门槛同理）

## Strategy

1. **首个失败信号原则**：从 seq 0 顺序扫到第一个异常（zero masks / 碰撞 /
   IK 失败 / 空抓），修它；后续报错多是它的下游。
2. **症状→原因对照表**：

   | 症状 | 可能原因 | 检查 |
   |---|---|---|
   | segment_sam3_* 返回 [] | 提示词不当 / 臂挡视野 / 遮挡 | sam3/ 标注图（含"未检到"帧）；先 TUCK 再观测 |
   | masks[0] 选错目标 | 多实例未消歧 / 臂被误检 | 面积过滤 50-12000px；按方位词排序 |
   | solve_ik RuntimeError | 目标不可达（x>0.45 / 腕限位） / 严格顶朝下 | 降 z 5cm 试；换倾斜姿态族；查 x/y |
   | close_gripper 后开度≈0 | 空抓：z 偏高 / 中心偏移 | 打印 grasp_z 对比 min_z |
   | 夹住但抬起掉落 | Yaw 不当 / 夹持点偏 | 试垂直偏航 90° 或沿 OBB 长轴逼近 |
   | move_to_joints RuntimeError | 路径碰撞 / 关节容差过严 | collision_events；长程改 execute_legs_rrt |
   | plan_grasp 返回空 | 掩码太小 / CGN 不在线 | log mask.sum() 应 >200px；检查 :8117 |
   | 图像全黑/双相机同图 | EGL 渲染损坏 | 引擎自愈会处理；反复出现查 MUJOCO_GL |

3. **3 次 replay 上限**（E.3 硬规则）：同一 seed 修 3 次不过 → 写 BLOCKED
   结论换方向，不无限重试。
4. **修复必须机制性**：优先"因为几何/动力学原因有效"的策略，拒绝拟合
   debug seed 的硬编码阈值/区域掩码/偏移（E.4 反过拟合条款）。

## Evidence

- 2026-08-04 "机械臂不动"虚惊：表象是臂不动，trace 显示 IK/RRT 规划期
  分钟级静默——修复=render 模式 stdout tee 实时回显，而非动控制链。
- 2026-08-05 深度"偏短 2.1cm"虚惊：表象是深度错，根因是测试尺寸假设
  过期（细高化前注释）——逐点 GT 核实后才定位，禁止凭单帧下结论。
- 2026-08-06 弹块事故：close_gripper 全速闭合弹飞方块，trace 碰撞事件
  直接定位 → set_gripper_ramp 渐进闭合修复。

## Limitations

- 对照表覆盖 Phase 0 已见症状；新症状先入 trace 取证再修，修完回报
  coordinator 扩充本表。
