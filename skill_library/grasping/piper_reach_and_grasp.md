# piper_reach_and_grasp

> **Purpose:** Piper 6 轴臂抓取/放置的可达性与姿态选择纪律
> **Ownership:** Coordinator adds generalizable patterns. Actors do not edit this file.

## Problem

Piper 是 6 轴臂（非 7 轴 Panda），腕限位 j5 ±70° 形成姿态死区：严格顶朝下
（quat=[0,0,1,0] 或 make_topdown_quat 的精确值）的 IK 在大片工作区不收敛；
盲目抄 Franka 任务代码的垂直下抓会在 solve_ik 阶段连环失败。此外基座系
x > 0.45m 的目标基本不可达（臂展+桌面安装几何决定），把目标点选在可达带外
会让任何姿态族都失败。

## When to Apply

- solve_ik 抛 RuntimeError / 连续多个位姿不收敛
- 抓取点 z 贴近桌面（<0.05m）或 x 接近/超过 0.45m
- close_gripper 后抬起物体掉落或空抓

## Strategy

1. **姿态族而非单姿态**：顶抓用倾斜姿态族（绕逼近轴滚转扫描由 solve_ik
   兜底链自动尝试）；精细贴桌任务（如擦板）用 `free_approach_roll=False`
   + 固定倾角（wipe 实测 38° 全姿态唯一整路径收敛）。
2. **可达性先行**：目标 x>0.45m 时不要硬解——把中间落点收回可达带，
   或换抓握点/推拨策略；放置前先 solve_ik 预解（先算后动铁律）。
3. **抓取 z 基准**：grasp_z 以点云 min_z（p5）+ 半物高为基准，别用 top_z
   直接下压（细高块会顶飞）；预抓高度 top_z + 0.10m。
4. **夹取验证**：close_gripper 后抬起，读 `obs["robot_joint_pos"][-1]`
   （开度 0..1）：>0.003 = 夹住；≈0 = 空抓 → 张开、回 TUCK、重新定位、
   降 2mm 重试。
5. **夹爪防冲击**：夹取小硬块用 `set_gripper_ramp(target, ticks=25)`
   渐进闭合——全速闭合实测会弹飞 4cm 方块。

### Code Sketch

```python
def verified_pick(cx, cy, grasp_z, quat, hover=0.10):
    """预抓→下压→渐进闭合→抬起→读开度验证。返回 True=夹住。"""
    open_gripper()
    move_to_joints(solve_ik(np.array([cx, cy, grasp_z + hover]), quat))
    move_to_joints(solve_ik(np.array([cx, cy, grasp_z]), quat))
    set_gripper_ramp(0.0, ticks=25)   # 渐进闭合防弹块
    move_to_joints(solve_ik(np.array([cx, cy, grasp_z + hover + 0.04]), quat))
    obs = get_observation()
    return float(obs["robot_joint_pos"][-1]) > 0.003
```

## Limitations

- x>0.45m 的可达带边界是桌面安装（基座 z=0.80）下的实测值；改安装/换
  本体须重测（sim2real 纪律：物理参数条目换本体重新验证）。
- 38° 是 wipe 平板贴桌的特解；其他任务优先用 free_approach_roll=True
  让兜底链扫滚转。
